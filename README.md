# Acizi Carboxilici - Chemistry Learning App 🧪🏆

An interactive educational desktop application designed to help users learn about carboxylic acids. The application features a comprehensive theoretical lesson followed by a 15-question interactive quiz to test your knowledge.

**🏆 Awarded 1st Place at the Infochim Competition (2022)**

## 🌟 Features

* **Interactive Lesson**: 8 pages of beautifully structured educational content about carboxylic acids.
* **Knowledge Quiz**: A 15-question multiple-choice quiz with real-time score tracking.
* **Graphical User Interface**: A fully customized graphical interface built with Python's Tkinter, using custom image assets for buttons, backgrounds, and quiz options.
* **Responsive Window**: Automatically centers the 1280x720 window on the user's screen for an optimal viewing experience.

## 🛠️ Tech Stack

* **Language**: Python 3.x
* **GUI Framework**: Tkinter (Standard GUI library for Python)
* **Image Processing**: Pillow (PIL)
